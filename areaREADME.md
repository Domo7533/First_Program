\# Rectangle Area Calculator



\## Description



This C# program calculates the area of a rectangle using variables for length and width.



\## Formula



Area of Rectangle = Length × Width



A = l × w



Where:



\* A = Area

\* l = Length

\* w = Width



\## Example



Given:



Length = 10



Width = 5



Calculation:



Area = 10 × 5



Area = 50



\## How to Run



1\. Open the project in Visual Studio or VS Code.

2\. Build and run the application.

3\. The program will display the length, width, and calculated area.
